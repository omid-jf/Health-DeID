Health-DeID
============

Health-DeID is a local, auditable, and resumable pipeline for de-identifying
clinical text and mapped structured fields. The Python API, command-line
interface, and single-user web UI operate on the same SQLite-backed run model.

.. important::

   Health-DeID is research software. It has not been validated or approved for
   diagnosis, treatment, clinical decision-making, or as a guarantee of legal
   or regulatory compliance.
